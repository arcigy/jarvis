# Analýza zmluvných šablón

Spracované vstupy:

- `PRÍLOHA Č. 1 PROJEKTOVÁ PRÍLOHA.docx`
- `RÁMCOVÁ ZMLUVA O POSKYTOVANÍ WEBOVEJ APLIKÁCIE.docx`
- doplnková univerzálna príloha vytvorená pre budúce prílohy

Odstránené alebo zovšeobecnené klientské údaje:

- Natureon Czech Design s.r.o.
- adresa, IČO, DIČ/IČ DPH, register a email klienta
- Jakub Horák a podpisové údaje klienta
- konkrétne kontaktné číslo klienta

Zovšeobecnené vecné časti:

- stolárske a nábytkové použitie nahradené klientskymi workflowmi, automatizáciami a aplikačnými modulmi
- materiálové katalógy nahradené dátovými katalógmi, konfiguráciami a pravidlami
- cenové ponuky nahradené dohodnutými výstupmi tam, kde pôvodný text viazal zmluvu na jeden typ aplikácie
- parametrické nábytkové moduly nahradené individuálnymi automatizačnými alebo aplikačnými modulmi

Ponechané pevné údaje:

- Arcigy s. r. o.
- sídlo, IČO, IČ DPH, register a email Arcigy
- Branislav Laubert ako zástupca poskytovateľa

Poznámka: výsledné DOCX sú univerzálne šablóny, nie právne posúdenie.

Budúce prílohy sa generujú cez `additionalAttachments[]` v `contract-intake.schema.json`.
